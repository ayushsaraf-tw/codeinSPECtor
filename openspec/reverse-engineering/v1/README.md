# Reverse Engineering Workspace

This directory is intended for outputs generated by the separate legacy reverse-engineering workflow.

## Relationship to OpenSpec

Reverse engineering and change planning are separate workflows:

```text
Legacy code
  -> reverse-engineering workspace
  -> canonical OpenSpec specs
  -> stakeholder validation
  -> normal OpenSpec change workflow
```

Do not create an OpenSpec change proposal merely to document existing behavior. Existing behavior belongs in the canonical `openspec/specs/` model once it has been reconstructed and validated.

## Suggested organization

```text
openspec/reverse-engineering/
├── README.md
├── system/            # optional system-level reconstruction artifacts
├── evidence/          # machine-readable or detailed evidence records
├── findings/          # contradictions, risks and investigation findings
└── views/             # generated presentation artifacts
```

These are supporting artifacts, not a competing source of truth.
